# 信号、接口与敏感电路

用于模拟/音频、晶振、采样反馈、数字接口、差分、ESD、RF 和天线。先读取 [统一原则与导航](pcb-layout-design-guidelines.md)；通道工整度和耦合方法见 [走线几何与层间耦合](routing-geometry-and-coupling.md)。

## 1. 模拟、音频与接地

混合信号布局的目标是控制噪声电流路径。先按功能分区，让开关电流、高速时钟和大电流回路避开 ADC 输入、基准、高阻节点及音频前端；不能只按“模拟/数字”标签切地。AGND/DGND 的连接服从器件指南和原理图，不能因网名不同自动加磁珠/0 Ω，也不能未经核对合并独立地网。[ADI 混合信号布局指南](https://www.analog.com/en/resources/analog-dialogue/articles/what-are-the-basic-guidelines-for-layout-design-of-mixed-signal-pcbs.html)

高阻输入、基准和放大器反馈短而局部集中，远离 SW、时钟和磁性器件。保护环、地屏蔽和局部挖铜依据漏电、寄生电容及器件资料决定，不要求所有敏感线旁铺地。

## 2. 晶振、复位与启动

将晶体/振荡器、负载电容、跨接/反馈元件及芯片相关引脚作为局部功能组。缩短必要连接和回流，减少过孔、支路和邻近铜变化，避开高速、大电流和开关节点。XIN/XOUT 通常不按普通差分对强制等长，具体拓扑和禁布以器件指南为准。

复位、启动配置和高阻控制网络检查上拉/下拉、RC、测试点、外部接口和上电状态。不能为减少交叉随意重映射或删除看似冗余的支路。

## 3. 采样、反馈与 Kelvin 路径

从规定采样点独立引出电压/电流检测，避免共享大电流铜颈、热连接或高 di/dt 回流。差分采样两线保持相似环境并靠近实际测量点；分流器 Kelvin 连接直接取自指定焊盘位置。检查采样点、参考地、完整路径及附近噪声源，不能仅凭同网连通判定正确。

## 4. 先判断数字接口的电气性质

读取控制器、对端、连接器和系统要求，记录模式、速率与边沿、端点、拓扑、阻抗、长度/偏斜预算、参考面、端接及换层限制。网络名相似不代表约束相同；串联器件两侧不同网名仍属于同一通道。

常见接口只作为分类入口：

| 类型 | 主要判断 |
|---|---|
| 差分高速 | 对内耦合/偏斜、参考、阻抗、换层和残桩 |
| 源同步总线 | 时钟/选通与数据的时序关系、拓扑和分组 |
| 单端控制 | 边沿、负载、串扰、上拉及状态 |
| 外部 DDR | 控制器专属字节组、DQ/DQS/地址控制拓扑与预算 |

## 5. 差分、换层和局部结构

差分两线保持相似参考环境、几何和换层结构，控制间距变化与焊盘不对称；必要偏离集中在短的扇出/连接器区域。减少无必要的过孔、支路和残桩；是否采用盲埋孔或背钻由频率、过孔模型和制造能力决定。[TI 高速接口布局指南，第3章](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)

受控阻抗路径逐层核对线宽、线距、参考层、连接器/串联器件焊盘、缩颈、过孔和附近铜。几何改变时记录位置、范围与依据。测试点、DNP 支路和备用接口按实际拓扑判断，不能把原理图规定的支路当作残线删除。

## 6. 长度与时序

先明确匹配对象、端点、计量方法和预算，再调长。差分对内偏斜、同组总线匹配和不同通道之间的关系分别处理；不能把所有高速线或所有 DDR 线机械等长。拓扑与通道稳定后在有连续参考的区域调长，控制蛇形自身耦合和邻线间距；没有匹配要求的网络不添加蛇形。

长度报告说明是否包含封装、焊盘、过孔垂直段、支路和器件内部延迟。几何等长不能替代时序、阻抗和器件模型验证。

## 7. 路径与几何取舍

满足固定位置、拓扑、间距、载流、阻抗、时序和回流后，比较整组通道，减少无必要长度、折弯和过孔。器件位置确实妨碍路径时才调整可移动器件。为通道组织作适度长度调整须检查相关预算；隔离、避障和时序补偿的绕行保留依据。详细流程见 [走线几何与层间耦合](routing-geometry-and-coupling.md)。

## 8. ESD 与外部接口

保护器件靠近受扰入口，使信号按设计顺序经过保护焊盘再进入板内；避免长支线连接 TVS。缩短保护器件到指定泄放参考的路径，保护前后线路避免长距离并行。泄放到信号地、机壳或其他参考由整机接地决定，不能自动并地。[TI ESD 布局指南](https://www.ti.com/lit/an/slva680a/slva680a.pdf)

电平转换、共模器件、滤波器和端接的位置按其在通道中的电气作用安排，不能只因“接口相关”全部挤在连接器旁。

## 9. CAN 与 RS-485 总线

先从原理图和系统连接图确认总线类型、收发器、节点角色、线缆与连接器、速率/边沿及主干和支线；区分板上短连接与板外多节点总线。按系统拓扑确定终端和 RS-485 失效保护偏置的数量、位置及是否可选，核对器件内置功能；终端属于总线端点约束，不能让每个节点都默认加终端。收发器到连接器的 CANH/CANL 或 A/B 应保持路径清晰、支线短且两线几何环境相近，按适用器件和线缆要求评估阻抗、回流、共模器件及分支反射；不机械套用高速差分对的等长预算。[TI CAN 终端与支线示例](https://www.ti.com/lit/ug/tidudq6/tidudq6.pdf)、[TI RS-485 设计指南](https://www.ti.com/lit/an/slla272d/slla272d.pdf)

外部接口按第 8 节安排 TVS、共模器件及其泄放路径，核对连接器到保护器件、保护器件到收发器的实际拓扑，避免保护支路形成明显长桩。隔离型接口分别核对逻辑侧与总线侧供电、参考地、爬电/电气间隙及跨隔离边界的铜、过孔和器件；隔离等级与间距以产品要求、器件资料及适用标准为准，不能因同为 CAN/RS-485 而共用固定值。[TI 数字隔离器设计指南](https://www.ti.com/lit/an/slla284g/slla284g.pdf)

## 10. RF 馈线与天线

馈线是受控传输路径；天线区域是辐射结构，两者分别处理。馈线核对目标阻抗、叠层、参考地、长度、转角、过孔和匹配器件顺序；匹配器件靠近规定端口并保持可调试性。

天线净空依据实际天线和整机方案逐层定义，覆盖铜、器件、螺丝、屏蔽罩、线缆、电池和外壳；不能将馈线下方参考地误删成天线禁铜，也不能照搬其他模块的净空尺寸。最终在外壳内验证匹配和无线性能。[ADI RF 铺铜说明](https://www.analog.com/en/resources/technical-articles/avoid-pclayout-gotchas-in-ismrf-products.html)
