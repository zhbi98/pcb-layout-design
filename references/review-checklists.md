# PCB 评审与交付清单

用于阶段评审和最终交付。先读取 [统一原则与导航](pcb-layout-design-guidelines.md)，再加载本次检查项指向的专题。状态使用“通过 / 不通过 / 待验证 / 不适用（说明原因）”；几何筛查、原生 DRC、仿真和样机测量分别记录。

## 1. 记录格式

问题统一记录：

`严重度 | 器件/网络/层/位置 | 观察与证据 | 适用要求 | 影响 | 建议或已做修改 | 复核方法与状态`

关键网络记录：

`设计版本/填铜状态 | 网络组与端点 | 层/位置 | 清单项 | 规则/限值 | 方法/检查层级 | 观察值/证据 | 状态 | 问题/复核`

按实际影响分阻断、高、中、低。待核实风险、风格问题和已确认违规分开；DRC 排除保留对象、原因与验证依据。

## 2. 关键网络完成或修改后的检查

高速接口、时钟、电源供回路径、敏感采样等按电气功能和实际端点分组；串联器件两侧不同网名仍作为同一路径。每组完成后立即检查；推挤、调长、换层、移动器件或重新填铜改变路径、邻线或参考结构后，重查受影响项。

- [ ] **回流连续性：**按[叠层、回流与电源](stackup-return-power.md#2-回流与参考铜)检查参考铜和换层回流。
- [ ] **阻抗连续性：**按[物理叠层](stackup-return-power.md#1-物理叠层与层用途)和[差分局部结构](signal-and-interface.md#5-差分换层和局部结构)检查逐层几何、缩颈、焊盘和过孔。
- [ ] **差分与时序：**按[长度与时序](signal-and-interface.md#6-长度与时序)检查对称、间距、偏斜、预算和蛇形自耦。
- [ ] **拓扑与残桩：**检查端接、测试点、DNP/备用支路和过孔残桩。
- [ ] **采样与反馈：**按[采样与 Kelvin](signal-and-interface.md#3-采样反馈与-kelvin-路径)检查采样点、参考地和噪声隔离。
- [ ] **大电流瓶颈：**按[电源铜宽与过孔](stackup-return-power.md#5-电源完整性铜宽与过孔)检查完整供回路径、最窄通路、压降和温升依据。
- [ ] **接口保护：**按[ESD 与外部接口](signal-and-interface.md#8-esd-与外部接口)检查保护顺序、泄放及保护前后耦合。
- [ ] **修改后关联复核：**检查邻线、连接、铜区、参考面和结构基线；重填受影响铜区并执行所需原生检查。

## 3. 布局评审

- [ ] 已读取工程已有规则，板框、分类边距、结构位置及确认状态明确。
- [ ] 原理图—封装映射、连接器方向、极性和底层视角正确。
- [ ] 按[布局与机械约束](layout-and-mechanics.md)完成模块、关键局部电路、扇出、通道及正反面检查。
- [ ] 器件间距有测量基准和工艺来源；大型、重型、发热及手工器件的固定、热与操作空间已检查。
- [ ] 测试、调试、校准和烧录方案已转化为覆盖范围、探针/夹具空间和参考地要求；敏感网络上的测试支路已评估。
- [ ] 全局/局部基准点、定位孔、夹持区及特殊孔工艺所需空间已落实；位号、Pin 1、极性和板版本标识有可行位置。
- [ ] 振动、板弯、分板应变、涂覆/灌封及线缆受力等适用环境约束已落实到器件与禁布区域。
- [ ] 多层板层用途、关键网络换层和叠层对称性有依据。
- [ ] 恢复相关飞线、层、铜区和机械对象后完成整体复核；未定项有状态。

## 4. 布线与规则评审

- [ ] 已从原理图实际端点和跨页路径完成功能分组；电源供回、大电流/开关、高速/时钟、敏感采样/反馈、控制/状态和普通低速网络的复合属性、优先级及验证方法明确。
- [ ] 分组已覆盖全部待布网络；未归组或功能不明的网络标为待核实，没有直接归入普通低速组。
- [ ] 反馈网络没有仅因名称归入普通控制；GND 已按功率回流、信号参考、屏蔽、泄放或机壳/隔离用途关联检查。
- [ ] 线宽、间距、过孔、网络类和自定义规则的来源与实际命中结果明确。
- [ ] 普通网络、跨模块交界和共享铜区未遗漏。
- [ ] 按[工整度流程](routing-geometry-and-coupling.md#14-工整度检查与局部整理流程)检查成组通道、局部几何和逐层视觉效果；布通或零 DRC 不代替本项。
- [ ] 已在 PCB 编辑视图中区分走线、铜区/禁布边界和其他图形；外围长绕行、折返及近包围路径均有端点追踪、保留原因或优化结果。
- [ ] 各网络组有通道骨架或等价规划；提交后仍为剩余网络保留合规出口，拥塞没有通过逐根钻缝、外围长绕行或不断推挤转嫁。
- [ ] 候选比较保留长度/绕行、过孔、折弯、层与参考、通道占用及保留/回退原因；硬约束未被综合评分抵消。
- [ ] 铜区逐层检查参数、连接、辐条、孤岛、细颈、优先级和净空；多用途分别评审。
- [ ] 盲埋孔、微孔、背钻、盘中孔、槽孔和压接孔等实际采用结构已核对层对、成品尺寸、填塞/盖帽及制造能力。
- [ ] 阻焊桥/开窗、钢网开口、散热焊盘和大铜不对称区域已按封装及装配工艺检查。
- [ ] 最终路径与层用途/换层记录一致，实际参考铜和铜分布已检查。
- [ ] 天线、机械与隔离净空逐层核查。
- [ ] 每组关键网络完成第2节适用项，结果对应最终路径和填铜。
- [ ] 最终版本完成原生 DRC、未连接和原理图一致性检查；排除有依据。

## 5. 制造与样机验证

- [ ] Gerber、钻孔、板框、叠层/阻抗和特殊工艺来自同一验证版本并独立查看。
- [ ] BOM、坐标、DNP、极性、变体和钢网要求一致。
- [ ] 基准点、定位孔、测试点、丝印/装配标识、板名版本及追溯信息在最终输出中可用且一致。
- [ ] 板厂/装配方完成适用 DFM，关键公差和检验方法有记录。
- [ ] 样机检查上电时序、负载端电压、纹波、瞬态和温升。
- [ ] 按接口与整机目标完成功能、信号质量、无线及 ESD/EMC 验证。

DRC 只检查已配置且工具可表达的规则，不能替代 SI、PI、热或整机验证。[KiCad PCB Editor](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)
