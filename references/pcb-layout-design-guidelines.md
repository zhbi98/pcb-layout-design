# PCB设计布局规范

本文件是 PCB 布局设计参考的导航入口。核心执行约束保留在 [SKILL.md](../SKILL.md)，具体方法按任务加载对应专题；不要为了一个局部任务读取全部参考。

## 1. 统一原则

1. 以当前工程、项目规格、器件资料、机械资料和选定制造/装配工艺为依据。区分硬约束、计算/仿真结果、经验候选值和案例实测。
2. 先满足产品、安全、电气、机械与制造硬约束。硬约束冲突时记录对象、来源、影响和状态，不能用布通率、外观、默认值或宽松经验抵消。
3. 在合格方案中比较整组可布线性、路径长度、折弯、过孔、通道、热和装配。单根最短、规则无报错或外观整齐都不是唯一目标。
4. 保留已确认的板框、结构件、叠层和有效规则；只在任务范围内修改有依据的对象。布局和布线可迭代，电路/引脚变更必须从原理图受控同步。
5. 每项规则保留一个详细归属。其他文件只给加载条件和链接，不复制完整步骤；外部链接用于依据追溯，不能代替本地执行动作和验收方法。

## 4. 来源与适用边界

正式项目记录合同采用的标准、器件资料和供应商工艺版本。专题中的厂商应用笔记用于解释机制和建立检查入口，其器件专属参数不能直接套用；社区资料只作线索，经器件/EDA/制造商原始资料和项目条件核对后才转成规则。

外部资料转成规则时记录：`来源与适用对象 | 项目适用原因 | 执行动作 | 检查方法 | 例外/状态`。资料链接失效不应使本地规则失去基本执行含义。

通用标准用途可从 [IPC 设计标准目录](https://www.ipc.org/ipc-design-standards)检索；EDA 的规则优先级、对象语义、编辑接口、填铜和检查行为以目标软件当前版本的官方文档为准。使用 KiCad 时可从 [KiCad PCB Editor 文档](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)核对；正式设计前重新确认软件与文件版本。
