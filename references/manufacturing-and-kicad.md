# 制造、装配与 EDA 规则

用于绑定板厂/装配工艺、检查已有规则、选择线宽/过孔和处理铜区，适用于 KiCad、Altium Designer、Cadence Allegro、EasyEDA 等 PCB EDA。先读取 [统一原则与导航](pcb-layout-design-guidelines.md)。电气用途的判断分别见 [叠层、回流与电源](stackup-return-power.md)和[信号、接口与敏感电路](signal-and-interface.md)。界面名称因软件和版本而异，应把本文概念映射到目标 EDA 的网络类、约束管理器、规则域、铜区及等价对象，并用原生检查确认实际生效。

## 1. 制造输入

制造条件绑定具体供应商、订单工艺和版本，至少包括层数/材料/板厚、铜厚、最小线宽/间距、孔径/环宽、孔到铜、阻焊桥、表面处理、外形/槽/分板、阻抗和特殊孔。装配条件包括钢网、最小器件/间距、贴装面、夹持方向、工艺边、焊接、AOI、返修和测试。能力下限不等于推荐设计值，也不能把某一层数或铜厚的能力用于所有订单。

正式项目应记录合同采用的 IPC 或客户标准版本。IPC-2221/2222、IPC-2152、IPC-2141、IPC-2226 分别可作为通用刚性板、载流、阻抗和 HDI 的检索入口；未取得正文时不能引用未经核实的条款或数值。[IPC 设计标准目录](https://www.ipc.org/ipc-design-standards)

## 2. 板边与装配工艺

分别检查铜到锣边/V割、孔到边、器件本体/操作包络到边、邮票孔连接处和 SMT 夹持区；明确从铜边、孔边、V割中心还是器件包络测量。外形公差用于结构配合，不能直接当作 DRC 铜边距。

采用嘉立创时，常规锣边铜间距可把官网能力值与设计留量建议分开记录，V割、邮票孔和工艺边使用各自要求；实际下单前核对所选材料、层数、铜厚及特殊工艺。不能把 5 mm 工艺边解释成所有器件到成品板边的统一距离。[嘉立创工艺能力](https://www.jlc.com/portal/vtechnology.html)、[工艺边说明](https://www.jlc.com/portal/q6i22406.html)

## 3. 设计开始前检查已有规则

在布局和走线前读取当前版本工程，不用模板或案例覆盖现状。至少检查：

| 对象 | 参数与判断 |
|---|---|
| 全局约束 | 最小线宽、铜间距、过孔外径/孔径、环宽及孔/板边限制；区分制造硬下限与编辑默认 |
| 网络类 | 线宽、间距、过孔、差分宽/距及网络分配；检查未分配和叠加后的有效属性 |
| 编辑预设 | 从工程或用户偏好设置读取设计者配置的常用线宽、过孔尺寸及当前选择，记录来源；列表存在不表示目标网络允许使用，空列表不代表可以任意选宽 |
| 自定义/局部规则 | 适用网络、层、区域、优先关系和局部例外，包含串联器件两侧匿名网络 |
| 孔类型 | 通孔、盲埋孔/微孔、尺寸与层对；核对叠层和订单能力 |
| 已有几何与排除 | 实际对象尺寸、层跨度和 DRC 排除；已有布线不一定符合当前规则 |

形成简要基线：

`网络/区域 | 规则来源/版本 | 默认值 | 有效强制限制 | 实际几何 | 单位 | 状态/冲突`

确需修改规则时记录原值、新值、依据和影响范围，并验证规则命中预期对象。不能通过放宽规则或关闭检查制造“零错误”。

### 3.1 结合网络和通道选择线宽

先查目标 EDA 是否提供设计者配置的常用线宽列表，再查目标网络、层和局部区域实际生效的默认/首选值及强制范围。常用列表可能保存在工程或用户偏好中；没有可读列表时记录“未取得”，不能从现有走线或软件内置值反推为设计者预设。各软件的入口不同：

| EDA | 常用线宽从哪里取 | 网络的有效线宽从哪里取 |
|---|---|---|
| KiCad | PCB 编辑器“板设置 → 预定义尺寸”；离线只读可核查当前 `.kicad_pro` 的 `board.design_settings.track_widths` | 网络类、分配、逐层调谐配置及自定义规则；核对 `net_settings.classes`、适用的 `.kicad_dru` 和原生检查。[KiCad 文档](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html) |
| Altium Designer | “Preferences → PCB Editor → Interactive Routing”中的 Favorite Interactive Routing Widths，属于用户偏好 | Constraint Manager 或 PCB Rules and Constraints Editor 的 Routing Width 规则：按网络/类、优先级及层读取 Min、Preferred、Max；受控阻抗时核对对应阻抗配置。[Altium 宽度规则](https://www.altium.com/documentation/altium-designer/pcb/design-rule-types/routing)、[交互布线](https://www.altium.com/documentation/altium-designer/pcb/routing/interactive) |
| Cadence Allegro / Allegro X | 不预设存在与 KiCad 相同的工程线宽列表；查实际工具的布线宽度选项 | Constraint Manager 的 Physical CSet、网络/网络类和局部覆盖；按层读取生效的线宽、缩颈及允许范围，考虑继承与优先级。[Cadence 约束集](https://community.cadence.com/cadence_blogs_8/b/pcb/posts/using-constraint-sets-to-manage-design-constraints)、[继承关系](https://community.cadence.com/cadence_blogs_8/b/pcb/posts/leverage-object-hierarchy-for-effective-constraint-management) |
| 嘉立创EDA专业版 | “设置 → PCB/封装 → 常用线宽”或布线时的常用线宽菜单，属于用户设置 | PCB“设计 → 设计规则 → 导线规则”及网络/分层/局部规则，读取最小、默认、最大线宽。[常用线宽](https://prodocs.easyeda.com/cn/pcb/settings-pcb/)、[设计规则](https://prodocs.easyeda.com/cn/pcb/design-design-rule/) |
| EasyEDA 标准版 | 布线时查看 Favorite Track Widths；按当前版本的设置界面核对列表来源 | “Tools → Design Rule”中读取目标网络应用的规则及线宽下限，并核对原生 DRC。[标准版设计规则](https://docs.easyeda.com/en/PCB/Design-Rule-Check/) |

界面、脚本字段和存储位置以实际软件版本为准。常用列表与项目规则分别记录来源；列表为空或不可访问时如实说明，不把默认值、现有走线宽度或编辑器当前选择冒充设计者预定义的可选线宽。

沿原理图实际引脚、跨页连接和串联器件识别源、负载、分支及回流，判断功率、普通控制、受控阻抗或敏感路径。结合持续/峰值电流、边沿、接口与器件资料确定候选值；不能只按网名、频率或电压分类。

按 [通道规划](routing-geometry-and-coupling.md#14-工整度检查与局部整理流程) 核对整组线宽、间距、焊盘、转角、过孔、两侧退让、参考铜和后续线路空间。先从设计者预设中选择同时满足电气、有效规则和通道要求的宽度；预设没有合格值时，记录缺口并依据项目要求确定新候选值，不能偷偷改用更细的预设或覆盖原有列表。功率线按预算加宽/铺铜，阻抗线保持逐层计算几何，普通线不为填满空间任意加粗。

通道不足时先检查无必要的过宽预设，再比较布局、通道和允许换层；不得降低必需间距或有效线宽限制。焊盘/BGA 扇出缩颈应限定位置、宽度和长度，离开限制区恢复主段几何，并验证载流或阻抗过渡。

记录：`网络/路径段 | 用途/依据 | 层 | 主段线宽 | 缩颈宽度/长度/位置 | 通道结果 | 状态`。

## 4. KiCad 约束层次和网络类

本节只在目标工程使用 KiCad 时加载；其他 EDA 按其官方规则优先级和作用域机制落实第 3 节基线，不照搬 KiCad 的字段名称或优先关系。

KiCad 10 全局 Constraints 的最小值不能被更具体规则降低；网络类中的线宽/过孔通常是默认布线值，不自动构成最大/最小 DRC 限制。需要强制检查的范围用适用的自定义规则表达，并检查多个规则叠加后的实际结果。[KiCad PCB Editor：设计规则](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)

按项目输入建立一般信号、电源、差分、接口和敏感网络类；逐层阻抗、长度/偏斜、天线/机械/隔离区域和局部例外按需设规则。网络前缀只可作命名线索，不能把同前缀的电源、控制和高速线误分为同一类。

空间宽松、无受控阻抗要求的低压普通信号，可把 `0.20 mm 线宽 / 0.20 mm 间距 / 0.60 / 0.30 mm 通孔` 作为与板厂讨论的初始编辑预设；这不是 IPC 统一数值、电源载流承诺或高密度扇出要求，不能覆盖已有项目规则。

## 5. 铜区参数与处理流程

创建或修改铜区前明确网络、层、用途、供回路径和禁布范围，区分轮廓与实际填充。功率、参考/回流、屏蔽和散热用途分别按 [叠层、回流与电源](stackup-return-power.md#6-功率铜与信号参考铜的取舍)检查。

| 常见铜区参数 | 检查 |
|---|---|
| Network / Layer | 网络归属和所在层 |
| Clearance | 与网络类/局部规则共同作用后的有效间距 |
| Minimum width | 增大后是否移除了必要细颈 |
| Pad connection | 直连、热连接或不连接及局部覆盖 |
| Thermal relief | 间隙、辐条宽度和实际接通 |
| Priority | 重叠区域最终边界 |
| Remove islands | 策略、阈值及实际残留铜 |

按以下流程处理：记录原参数和填充状态；规划铜区/禁布、连接和缝合；设置参数并用原生工具填充；逐层检查焊盘/过孔接入、辐条、孤岛、细颈、尖角碎铜、优先级和净空；复核参考面、电源通路、高速/RF 邻近铜、敏感节点和结构；运行 DRC/未连接检查并更新 [关键网络检查](review-checklists.md#2-关键网络完成或修改后的检查)。后续几何或规则变化影响填充时重新执行。

无用途浮空铜应清除；有用途铜须有效连接。不能为了消除孤岛连接不同地网或隔离两侧。参数合规、几何连通和性能验证分别记录，原生填充不可用时不能用旧填充或静态图像证明通过。

## 6. 热、焊接与安全间距

功率焊盘和铜区同时考虑载流、散热、焊接和返修。直连/热连接、辐条、过孔阵列和散热焊盘按器件封装、钢网、焊接与温升验证，不能统一要求全直连或全热焊盘。

电气间隙和爬电距离由工作/瞬态电压、污染等级、材料组、涂覆、海拔、适用安全标准和结构决定；沿表面路径与空气距离分别检查。普通信号 DRC 间距不能替代安规设计，缺少产品类别和环境输入时不得给出验收结论。

## 7. 可测试与可编程性

在布局阶段确定量产测试、调试、校准和烧录方案，不能等布线完成后用剩余空间补测试点。按测试方案确认电源、地、复位、启动、通信及关键模拟/功率节点的覆盖范围；测试点应具有探针可达空间、稳定参考地和清楚网络标识，并避开外壳、夹具、器件本体、焊点、板边夹持及分板受力区。双面测试、细间距探针、并行测试和 ICT/飞针能力须绑定实际夹具与装配流程。

测试焊盘、连接器和 DNP 支路会形成电气支路；高速、RF、高阻、时钟和敏感采样网络必须评估残桩、寄生和泄漏，不能为提高覆盖率破坏信号路径。烧录/调试接口同时核对上电顺序、电平、启动状态、防反接、外部供电冲突和量产后的访问/禁用策略。

## 8. 特殊孔、阻焊、钢网、标识与基准点

通孔、盲埋孔、微孔、背钻、盘中孔、槽孔及压接孔分别核对层对、成品孔径、公差、纵横比、环宽、孔到铜、塞孔/填孔/盖帽、阻焊开窗和供应商能力。叠孔或错列微孔、盘中孔和背钻属于明确指定的制造结构，不能由 Agent 为方便逃线自行采用；焊盘入口、过孔电流和可靠性按最终成品结构验证。

阻焊桥、阻焊扩展、开窗、塞孔以及钢网开口/减锡/分窗按封装、焊接工艺和装配方要求检查，尤其关注细间距器件、裸露散热焊盘、盘中孔、连接器和大铜不对称区域。不能只因 EDA 默认值通过 DRC 就认定可焊。

全局/局部基准点、工艺定位孔和夹持区按装配与拼板方案设置，确认铜面、阻焊开窗、周围净空、所在面和可视性。位号、Pin 1、极性、接口名称、测试点名称、板名/版本及必要追溯标记应可读且不压焊盘、开窗、孔槽或分板区；底层文字方向和镜像在制造输出中复核。法规或客户标志仅在具备使用依据时放置。

## 9. 环境可靠性与 EMC 结构边界

依据产品环境检查温度循环、振动/跌落、板弯、湿气/污染、腐蚀、清洗和三防涂覆。大型、重型、高器件、连接器、线缆受力点及板边器件检查固定和应力释放；MLCC、BGA、晶振和脆性器件避开预期板弯、螺钉压紧和分板高应变区。涂覆、灌封、导热材料和散热器应定义禁涂/接触/返修区，并重新核对爬电、热和 RF 影响。

外部接口处同时规划滤波、ESD 泄放、屏蔽层/机壳连接和信号参考转换。明确机壳地、保护地、数字地、模拟地及隔离边界的连接意图；屏蔽罩接地点、板边接地、安装孔和连接器外壳不能仅因同名或几何接近而自动合并。最终 EMC 结论依赖整机线缆、外壳和样机测试，PCB 几何检查只记录设计依据与待验证项。

## 10. 制造输出检查

制造包绑定同一已验证版本，独立查看层序、比例、原点、钻孔/槽、板框、镜像、底层方向和特殊工艺。装配包核对 BOM、坐标、DNP、极性、变体和钢网要求。板厂 DFM、样机 SI/PI、热与整机验证分别记录，不能互相替代。
