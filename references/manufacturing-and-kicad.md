# 制造、装配与 EDA 规则

用于绑定板厂/装配工艺、检查已有规则、选择线宽/过孔和处理铜区，适用于 KiCad、Altium Designer、Cadence Allegro、EasyEDA 等 PCB EDA。先读取 [统一原则与导航](pcb-layout-design-guidelines.md)。电气用途的判断分别见 [叠层、回流与电源](stackup-return-power.md)和[信号、接口与敏感电路](signal-and-interface.md)。界面名称因软件和版本而异，应把本文概念映射到目标 EDA 的网络类、约束管理器、规则域、铜区及等价对象，并用原生检查确认实际生效。

## 1. 制造输入

制造条件绑定具体供应商、订单工艺和版本，至少包括层数/材料/板厚、铜厚、最小线宽/间距、孔径/环宽、孔到铜、阻焊桥、表面处理、外形/槽/分板、阻抗和特殊孔。装配条件包括钢网、最小器件/间距、贴装面、夹持方向、工艺边、焊接、AOI、返修和测试。能力下限不等于推荐设计值，也不能把某一层数或铜厚的能力用于所有订单。

正式项目应记录合同采用的 IPC 或客户标准版本。IPC-2221/2222、IPC-2152、IPC-2141、IPC-2226 分别可作为通用刚性板、载流、阻抗和 HDI 的检索入口；未取得正文时不能引用未经核实的条款或数值。[IPC 设计标准目录](https://www.ipc.org/ipc-design-standards)

## 2. 板边与装配工艺

分别检查铜到锣边/V割、孔到边、器件本体/操作包络到边、邮票孔连接处和 SMT 夹持区；明确从铜边、孔边、V割中心还是器件包络测量。外形公差用于结构配合，不能直接当作 DRC 铜边距。

采用嘉立创时，常规锣边铜间距可把官网能力值与设计留量建议分开记录，V割、邮票孔和工艺边使用各自要求；实际下单前核对所选材料、层数、铜厚及特殊工艺。不能把 5 mm 工艺边解释成所有器件到成品板边的统一距离。[嘉立创工艺能力](https://www.jlc.com/portal/vtechnology.html)、[工艺边说明](https://www.jlc.com/portal/q6i22406.html)

## 3. 设计开始前检查已有规则

在布局和走线前读取当前版本工程，不用模板或案例覆盖现状。至少检查：

| 对象 | 参数与判断 |
|---|---|
| 全局约束 | 最小线宽、铜间距、过孔外径/孔径、环宽及孔/板边限制；区分制造硬下限与编辑默认 |
| 网络类 | 线宽、间距、过孔、差分宽/距及网络分配；检查未分配和叠加后的有效属性 |
| 编辑预设 | 可选尺寸和当前选择；列表存在不表示目标网络允许使用 |
| 自定义/局部规则 | 适用网络、层、区域、优先关系和局部例外，包含串联器件两侧匿名网络 |
| 孔类型 | 通孔、盲埋孔/微孔、尺寸与层对；核对叠层和订单能力 |
| 已有几何与排除 | 实际对象尺寸、层跨度和 DRC 排除；已有布线不一定符合当前规则 |

形成简要基线：

`网络/区域 | 规则来源/版本 | 默认值 | 有效强制限制 | 实际几何 | 单位 | 状态/冲突`

确需修改规则时记录原值、新值、依据和影响范围，并验证规则命中预期对象。不能通过放宽规则或关闭检查制造“零错误”。

## 4. KiCad 约束层次和网络类

本节只在目标工程使用 KiCad 时加载；其他 EDA 按其官方规则优先级和作用域机制落实第 3 节基线，不照搬 KiCad 的字段名称或优先关系。

KiCad 10 全局 Constraints 的最小值不能被更具体规则降低；网络类中的线宽/过孔通常是默认布线值，不自动构成最大/最小 DRC 限制。需要强制检查的范围用适用的自定义规则表达，并检查多个规则叠加后的实际结果。[KiCad PCB Editor：设计规则](https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html)

按项目输入建立一般信号、电源、差分、接口和敏感网络类；逐层阻抗、长度/偏斜、天线/机械/隔离区域和局部例外按需设规则。网络前缀只可作命名线索，不能把同前缀的电源、控制和高速线误分为同一类。

空间宽松、无受控阻抗要求的低压普通信号，可把 `0.20 mm 线宽 / 0.20 mm 间距 / 0.60 / 0.30 mm 通孔` 作为与板厂讨论的初始编辑预设；这不是 IPC 统一数值、电源载流承诺或高密度扇出要求，不能覆盖已有项目规则。

### 4.1 结合网络和通道选择线宽

1. 沿原理图实际引脚、跨页连接和串联器件识别源、负载、分支及回流，判断功率、普通控制、受控阻抗或敏感路径。结合持续/峰值电流、边沿、接口与器件资料确定候选值；不能只按网名、频率或电压分类。
2. 按 [通道规划](routing-geometry-and-coupling.md#14-工整度检查与局部整理流程) 核对整组线宽、间距、焊盘、转角、过孔、两侧退让、参考铜和后续线路空间。在满足电气和制造的候选值中选择；功率线按预算加宽/铺铜，阻抗线保持逐层计算几何，普通线不为填满空间任意加粗。
3. 通道不足时先检查无必要的过宽预设，再比较布局、通道和允许换层；不得降低必需间距或有效线宽限制。焊盘/BGA 扇出缩颈应限定位置、宽度和长度，离开限制区恢复主段几何，并验证载流或阻抗过渡。

记录：`网络/路径段 | 用途/依据 | 层 | 主段线宽 | 缩颈宽度/长度/位置 | 通道结果 | 状态`。

## 5. 铜区参数与处理流程

创建或修改铜区前明确网络、层、用途、供回路径和禁布范围，区分轮廓与实际填充。功率、参考/回流、屏蔽和散热用途分别按 [叠层、回流与电源](stackup-return-power.md#6-功率铜与信号参考铜的取舍)检查。

| 常见铜区参数 | 检查 |
|---|---|
| Network / Layer | 网络归属和所在层 |
| Clearance | 与网络类/局部规则共同作用后的有效间距 |
| Minimum width | 增大后是否移除了必要细颈 |
| Pad connection | 直连、热连接或不连接及局部覆盖 |
| Thermal relief | 间隙、辐条宽度和实际接通 |
| Priority | 重叠区域最终边界 |
| Remove islands | 策略、阈值及实际残留铜 |

按以下流程处理：记录原参数和填充状态；规划铜区/禁布、连接和缝合；设置参数并用原生工具填充；逐层检查焊盘/过孔接入、辐条、孤岛、细颈、尖角碎铜、优先级和净空；复核参考面、电源通路、高速/RF 邻近铜、敏感节点和结构；运行 DRC/未连接检查并更新 [关键网络检查](review-checklists.md#2-关键网络完成或修改后的检查)。后续几何或规则变化影响填充时重新执行。

无用途浮空铜应清除；有用途铜须有效连接。不能为了消除孤岛连接不同地网或隔离两侧。参数合规、几何连通和性能验证分别记录，原生填充不可用时不能用旧填充或静态图像证明通过。

## 6. 热、焊接与安全间距

功率焊盘和铜区同时考虑载流、散热、焊接和返修。直连/热连接、辐条、过孔阵列和散热焊盘按器件封装、钢网、焊接与温升验证，不能统一要求全直连或全热焊盘。

电气间隙和爬电距离由工作/瞬态电压、污染等级、材料组、涂覆、海拔、适用安全标准和结构决定；沿表面路径与空气距离分别检查。普通信号 DRC 间距不能替代安规设计，缺少产品类别和环境输入时不得给出验收结论。

## 7. 制造输出检查

制造包绑定同一已验证版本，独立查看层序、比例、原点、钻孔/槽、板框、镜像、底层方向和特殊工艺。装配包核对 BOM、坐标、DNP、极性、变体和钢网要求。板厂 DFM、样机 SI/PI、热与整机验证分别记录，不能互相替代。
