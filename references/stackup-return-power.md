# 叠层、回流与电源

用于多层板分层、参考面、铺铜用途、电源环路和载流设计。先读取 [统一原则与导航](pcb-layout-design-guidelines.md)；铜区工具参数见 [制造与 KiCad](manufacturing-and-kicad.md#5-铜区参数与处理流程)。

## 1. 物理叠层与层用途

记录从顶到底的物理层序、EDA 层名、铜厚、芯板/半固化片和压合后介质厚度、材料参数及板厂叠构版本。受控阻抗由线宽、线距、介质、铜厚和周围铜共同决定；缺少这些条件时只能给候选几何，不能声称阻抗通过。四层或六层本身不构成合格叠层。[TI 高速接口布局指南](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)

在板框和固定结构基线下，共同规划关键网络、连续参考面、电源供回路径和换层位置，再安排普通信号。内层不自动等于高速层，外层也不自动排除高速；禁止因层名假定参考铜连续。

对关键网络组记录：

`端点/网络组 | 首选/备选层 | 参考层/网络 | 允许层对与过孔 | 换层回流 | 阻抗/时序/残桩依据 | 状态`

布局和扇出中验证通道；不足时依次比较可移动器件、通道、网络分层和叠层方案。不能为减少过孔选择回流更差的路径，也不自动增加层数。最终路径、材料或铜区变化后更新记录并复核阻抗、回流、载流和制造层映射。

## 2. 回流与参考铜

沿关键线路同时显示信号层和参考层，检查参考网络、连续性、槽/孔/板边、密集反焊盘及换层回流。高速信号避免跨参考面分割；同一 GND 参考层间换层时按需要在信号过孔附近提供实际接入相应层的地缝合。跨不同电源参考时，地过孔不能代替正确的回流转换；优先调整路径或叠层。差分信号仍须检查共模回流。[TI 高速接口布局指南，第2.4节](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)

信号参考铜区以所服务的信号通道为对象。记录接口、端点、模式/边沿、参考层和网络；检查信号到参考面的距离、铜边和周围铜变化。表层地铜不自动替代下方参考面，长细颈或远处过孔的直流接地也不能证明高频回流充分。增减邻近铜后重新评估阻抗、反射、耦合和偏斜；局部屏蔽见 [走线几何与层间耦合](routing-geometry-and-coupling.md#23-同层串扰与局部屏蔽)。

## 3. 叠层对称性与铜分布

比较板厚中心两侧对应层的铜厚、材料和介质结构，优先使用板厂验证叠构。不对称方案需要制造评估，偶数层不能自动判定通过。

主要铜区成形后和最终填铜后，逐层检查整板及局部的密集/稀疏区域，并结合铜厚、拼板和工艺边判断。全层覆盖率相近不能证明局部分布均衡。处理铜分布时不能切碎参考面、缩窄载流路径、侵入天线/隔离净空或放置无用途浮空铜；板外工艺补铜和成品板电气铜分别处理。[Eurocircuits 铜分布说明](https://www.eurocircuits.com/technical-guidelines/panel-guidelines/copper-distribution-on-a-panel/)

## 4. 开关电源与去耦

依据器件资料画出各开关状态的高 di/dt 电流路径，识别输入旁路、开关管、整流/同步器件、电感及输出电容组成的关键环路。输入/输出电容、功率器件和电感围绕 IC 相关引脚布置；SW 等高 dv/dt 节点只保持实现功能所需面积，远离反馈、基准、晶振和敏感采样。

反馈从规定采样点引出，避开 SW 和磁性器件；不能以铜区直流相连代替 Kelvin/指定采样路径。EN、补偿、软启动等外围按实际功能处理，不因封装相同强行统一。

去耦按实际电源引脚、电源域和回流组织。缩短“电源引脚—电容—地/回流引脚”的高频环路，检查焊盘入口、过孔和参考层；投影距离近不证明环路短。电容顺序由阻抗目标、封装寄生、频率和器件指南决定，不能仅按标称容值排序。

## 5. 电源完整性、铜宽与过孔

记录持续/峰值和动态电流、铜厚、环境、允许压降/温升、负载瞬态及源到负载和回流路径。初步目标阻抗可用 `允许瞬态电压变化 / 电流阶跃` 作为预算，但不代替频率相关分析或样机测试。

追踪入口焊盘、保护器件、铜皮细颈、热连接辐条、过孔、连接器和回流。空间允许时，大电流供回路径优先连续、短而宽的铜区或电源平面；不能用“每安培固定宽度/过孔数”的经验替代电流、铜厚、板厚、孔壁、压降和温升评估。功率主干和分支按各段实际电流处理。

空间不足时调整可移动器件、通道或叠层；局部缩颈须限定位置、宽度和长度并验证载流、压降和温升。SW 节点不能因“功率线应加宽”而无限扩大。完整方法参考 [IPC 设计标准目录](https://www.ipc.org/ipc-design-standards)中的 IPC-2152 用途说明。

## 6. 功率铜与信号参考铜的取舍

同一 GND 铜区可能同时承担功率回流、信号参考、屏蔽和散热。每种用途分别检查：

| 用途 | 检查重点 |
|---|---|
| 功率载流/回流 | 完整供回路径、最窄有效通路、压降、温升和动态环路 |
| 信号参考/回流 | 所服务信号、参考连续性、换层回流、阻抗和耦合 |
| 局部屏蔽 | 干扰源/受扰网络、实际接地、邻近铜对阻抗的影响 |
| 散热 | 焊盘归属、热扩散、连接方式、装配和温升 |

功率通路变化后检查参考面是否被收窄或切断；参考铜边界变化后检查载流和热是否恶化。不能按 GND/VCC 网名自动切分、合并独立地网或认定用途通过。
