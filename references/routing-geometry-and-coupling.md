# 走线几何与层间耦合

供 [SKILL.md](../SKILL.md) 在规划走线方向、整理转角及检查串扰时按需读取。本文将项目偏好与公开技术依据分开，避免将简化经验写成无条件规则。资料核对日期：2026-09-09。

## 1. 转角与走线形状

### 1.1 本项目默认几何

主通道横平竖直，允许 ±45° 连接和适当圆弧；避免无必要的锐角折返、直角硬拐弯和连续碎折线。保持完整回流与固定端点，在满足约束的候选方案中兼顾路径长度、通道组织和几何简洁，按第 1.4 节比较整组收益；不为强行对齐造成无收益的绕行或换层。这是本 Skill 采用的设计风格，不能冒称 IPC 对所有线路的统一强制规定。

TI SCAA082A 第 2.5 节建议用两个 45° 转向或圆弧替代直角弯折；SPRAAR7J 第 3.11 节对其讨论的高速差分给出更平缓的角度示例。应查看具体指南的角度定义，不能认为“软件开了 45° 模式”就满足所有高速接口。[TI SCAA082A](https://www.ti.com/lit/an/scaa082a/scaa082a.pdf)、[TI SPRAAR7J](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)

### 1.2 避免把三种角度混淆

以无分支线路 A→B→C 为例：

| 量 | 定义 | 常见例子 |
|---|---|---|
| 线段方向 | 相对 PCB X 轴的方向 | 水平 0°、垂直 90°、斜线 ±45° |
| 行进方向改变 | A→B 与 B→C 的方向差，取 0°–180° | 直行 0°，斜切转向 45°，直角硬转 90° |
| 顶点射线夹角 | B→A 与 B→C 的较小夹角 | 直行 180°，斜切 135°，直角 90°，锐角折返小于 90° |

因而“45° 走线”通常是好的斜切，不能按“45 小于 90”误报为锐角。圆弧用切线连续性及适用半径/间距检查；铜多边形凹口、矩形焊盘角和分支节点另行处理。

### 1.3 AI 检查和修改方法

1. 从当前工程识别真实连接关系。只有同层、同网、共享连接顶点的连续路径才进入普通转角检查；分支、焊盘、过孔与交叉按对象类型解释。
2. 优先标出修改区域的直角硬转、锐角折返、多余短折线、未接入主路径的残段，以及焊盘/铜区入口的细颈。原理图规定的支路与端接不当作垃圾线删除。
3. 以工具精度或明确公差处理坐标舍入误差；不要因为微小浮点误差将 45° 判为不规则，也不能用任意大容差合并不同节点。
4. 调整拐角时重新检查邻线间距、连接、铜区及长度；差分两线必须一起评估，避免一侧改圆弧后引入未处理的偏斜。
5. 保留有依据的非标准角度、射频结构、旋转封装扇出与专用调长；记录例外的电气或机械原因。不要移动手动确认的结构件、固定接口或焊盘来强行吸附网格。

转角主要是一个几何检查入口；严重度仍应由适用规则及电气/制造影响决定。本文不设“只要直角必失败”或“锐角必然蚀刻失败”的统一结论。

### 1.4 工整度检查与局部整理流程

在布线前规划通道，每组布线基本成形后、用户请求局部美化时，以及最终交付前检查任务范围内的工整度。接手规则、模块布局与关键网络顺序沿用 Skill 第 3–5 节；仅审查任务输出问题和建议，不执行修改。线已布通是中间状态，工整度须在实际几何中单独检查，不能用零未连接或 DRC 通过代替。

**先规划整组通道，再逐根落线：**

1. **划分适合共用通道的连接。**结合原理图模块、实际端点、分层与参考面，识别同一区域往返的连接，明确入口、出口、瓶颈和需独立避让的网络。功能归属相同不代表可以紧密并行；差分对、时钟、敏感模拟和功率回路按各自约束处理。通道是空间规划，各网络保持独立连接，不合并成一条电气主干。
2. **预留容得下整组的空间。**按实际线宽、网间间距、与障碍物的退让及参考铜需求估算通道宽度；可用 `各线宽之和 + 相邻线间距之和 + 两侧所需退让` 作直线段初筛，拐角、扇出、过孔与铜连接另查。优先为最受约束的组保留通道，再安排普通线；不让先布的一根线占满入口，迫使其余连接各自绕远。沿端点自然顺序分配各线位置，不能为消除交叉擅自交换引脚。
3. **形成连贯主段与简洁进出线。**适合共用通道的线路保持稳定的相对次序、方向和满足电气要求的间距；转向集中在协调的区域，以错开的平行斜切保持转角处间距，不要求所有拐点同坐标。尽量在端点附近完成必要扇出与分流，避免中途反复散开、汇拢或绕过同一障碍物的不同侧。主段按第 1.1 节选方向；短而直接且参考连续的长斜线可以保留，不机械改成更长的阶梯，也不强行沿板边绕行。
4. **边试布边调整，按组回看。**在拉线过程中发现出线方向或器件间相对位置妨碍通道顺畅时，按 [布局与布线迭代](layout-and-mechanics.md#5-布局与布线迭代) 微调可移动器件，再继续试布；每完成一个通道查看整组及邻域。后续线路只能钻缝、反复折返或大幅绕行时，重新分配通道，必要时局部拆线重布。不能只修补单根线的拐角而保留导致散乱的整体路径。

通道协调允许在时序、载流、回流和隔离等要求满足时，接受有明确整体收益的适度长度调整；比较整组路径、瓶颈、折弯与过孔，记录相关代价。不能只优化某一根线的最短距离，也不能为视觉均匀把全部间距收紧到 DRC 下限。缺少关键时序或耦合依据时，不把高风险几何变更认定为已验证改善。通道组织属于项目方法；差分间距、参考面和转弯的电气边界参考 [TI SPRAAR7J，第 2.4、3.1–3.4、3.11 节](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)，不直接套用其接口参数。

先满足适用的电气、机械与制造约束，再在可行路径中减少无意义的复杂度。以下为项目整理准则，不能转换成适用于所有网络的固定线宽、间距或几何评分：

| 检查对象 | 整理动作 | 必须保留的边界 |
|---|---|---|
| 方向、拐角与碎折线 | 按第 1.1–1.3 节统一主方向，简化多余折返和短碎线段 | 保留固定端点、有依据的扇出、射频结构及调长段 |
| 线宽与缩颈 | 同层同约束路径保持合理连续，检查反复变宽变窄及过长缩颈 | 不把不同层、网络或局部阻抗结构强制设成同一宽度；缩颈按载流和阻抗要求验证 |
| 间距与成组通道 | 检查预留空间、相对次序、转弯区域及进出线；修正无必要的忽聚忽散、重复绕障与间距突变 | 无关信号不为整齐而紧密长距离并行；差分间距及参考铜关系按接口要求保持 |
| 焊盘出线与过孔 | 对条件相似的引脚采用一致、简洁的扇出方式，减少不必要换层 | 不为过孔排成直线拉长关键路径；保留载流、散热及换层回流所需过孔，检查过孔避让是否切割参考铜 |
| 绕行与通道瓶颈 | 排查可移动器件布局、通道分配及布线顺序，按原因比较局部改线和布局调整 | 不为美化扩大范围或移动已确认结构件；功率缩颈和宽度调整按 [线宽选择](manufacturing-and-kicad.md#41-结合网络和通道选择线宽) 处理 |

按受影响范围执行以下流程，不为轻微风格差异重布全板：

1. **保留可比较的基线。**确定目标网络、端点、层、邻域及现有约束；记录与拟改动有关的指标，沿用第 4 节的证据格式。风格问题与已确认违规分别标记。
2. **先整理通道，再整理局部几何。**按上述方法复核整组路径，优先消除瓶颈、重复绕障、折返和多余换层，再协调转角、扇出和线宽过渡。拓扑及通道基本稳定后，才按明确的时序预算完成调长；不能给没有匹配要求的网络添加蛇形线。高速长度、匹配与参考结构依据 [TI SPRAAR7J，第 2–3 节](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf) 及当前接口指南判断。
3. **每次修改后复核实际影响。**推挤影响的邻线也纳入检查。长度、换层、耦合、参考铜或载流截面变化时，重查 [关键网络检查](review-checklists.md#2-关键网络完成或修改后的检查)；影响铜区时按 [铜区流程](manufacturing-and-kicad.md#5-铜区参数与处理流程) 重新填充。长度增加或换层须说明原因并检查预算与收益。
4. **按结果保留或恢复。**引入违规、破坏固定对象，或使原有性能依据失效且无法完成所需复核时，恢复该次可逆的美化修改。原有问题仍记录为未解决，不因恢复基线而标为通过；实际修复任务缺少验证条件时，按 Skill 的能力边界交付状态。
5. **逐层查看并按条件结束。**使用当前版本的 PCB 视图或原生导出图，逐个受影响信号层检查区域全貌，并放大通道瓶颈和焊盘进出线；同时核对相邻参考层。可暂时隐藏填铜或只显示铜区轮廓观察路径组织，再恢复实际填充检查回流与铜连接。对比前后时保持相同区域、缩放和图层可见性，并至少完成一次区域整体回看，避免只看单根高亮线。

   当前范围内通道组织连贯、必要扇出和分流清楚、可修复的多余绕行/反复聚散/碎折线已处理，且适用约束已复核、保留例外有依据时，才将工整度标为已检查。将发现的位置或网络、处理结果及保留原因并入原有记录；无法获得可靠视图时标注“视觉工整度未验证”。不追求全板统一外观评分或无限减少折弯、过孔。最终检查沿用 [评审与交付清单](review-checklists.md)。

## 2. 如何判断层间耦合

“感应”不是足够具体的发现名称。TI 将邻近线路的串扰归因于不期望的电容和电感耦合；检查应关注干扰源、受扰网络、相对位置及参考结构。[TI SCAA082A，第 1.4 节](https://www.ti.com/lit/an/scaa082a/scaa082a.pdf)

### 2.1 先看实际叠层

下面仅是判断模型，S 表示信号层，G 表示在该区域连续、正确接地的参考平面。

| 层次关系 | 初步判断 | 下一步 |
|---|---|---|
| S1–介质–S2 | 相邻信号层，可能存在宽边耦合 | 避免长距离投影重叠/近平行，增加错位、缩短相邻段，必要时改变通道或叠层 |
| S1–G–S2 | 中间有地平面提供隔离 | 不因方向相同自动报错；核对 G 在该区域是否连续及过孔处的场/回流转换 |
| S1–分割电源/稀疏地铜–S2 | 隔离和参考环境随位置变化 | 打开实际铜区检查；不能按层名认定屏蔽已经成立 |
| 开关节点–介质–敏感线路 | 高噪声源与受扰电路相邻 | 优先空间分离并查器件禁布要求，不能只靠正交交叉 |

正交和缩短平行段是减少耦合的措施，不是耦合为零的证明。ADI 的布局指南同时讨论物理隔离、减少平行段和地平面屏蔽；本表是结合这些机制形成的检查策略，不能用于代替实际串扰仿真。[ADI 高速 PCB 布局指南：Routing and Shielding](https://www.analog.com/en/resources/analog-dialogue/articles/high-speed-printed-circuit-board-layout.html)

### 2.2 正交交叉的边界

- 对没有完整中间地层的相邻信号层，可用不同主方向减小平行重叠；空间允许时仍优先分开关键网络。
- 主方向不是每段的绝对禁令，也不是让两个差分成员互相正交的理由。P/N、所需耦合结构及信号—回流关系需要按其功能保持。
- 同一层不能通过“正交相交”分离两个不同网络，那会短路；投影交叉只讨论不同物理层。
- 有连续地平面隔开时，不应为了禁止投影重叠额外增加绕线和换层；有严格隔离要求时仍按专属指南检查。
- 如果器件指南更严格，执行专属要求。NXP AN13335 对其 xMII 场景提出避免相邻层信号交叉，以及在相关交叉场景安排连续层隔离等要求，说明通用“90° 交叉更好”不能直接变成通行证。[NXP AN13335，第 2.1.2、3.2.4 节](https://www.nxp.com/docs/en/application-note/AN13335.pdf)

### 2.3 同层串扰与局部屏蔽

检查无关网络的平行距离、长度及边沿；时钟、开关噪声与高阻模拟/复位等组合优先评估。间距不能只按线宽倍数推断效果，还需考虑信号至参考面的距离。NXP 的 xMII 示例明确将基材高度纳入间距讨论，其数字不能直接移植到其他接口。[NXP AN13335，第 2.1.2 节](https://www.nxp.com/docs/en/application-note/AN13335.pdf)

保护地线/铺铜必须有适当连接，不能把浮空细铜视为有效屏蔽。邻近覆铜会改变局部参考结构和受控阻抗，应与信号几何一起评估。不要为插入一条地线而破坏既定差分间距或挤出不满足工艺的细铜。[ADI ISM-RF PCB 布局：Ground Planes and Copper Pours](https://www.analog.com/en/resources/technical-articles/avoid-pclayout-gotchas-in-ismrf-products.html)

## 4. 操作检查记录

通用记录格式、状态和修改后复核沿用 [关键网络检查](review-checklists.md#2-关键网络完成或修改后的检查)。本专题仅补充几何与耦合所需证据，不另建重复报告：

| 项目 | 最少记录 |
|---|---|
| 拐角/折返 | 角度定义、对象类型、修改前后几何 |
| 同层并行 | 干扰源与受扰网络、边到边间距、平行范围 |
| 跨层重叠 | 物理层对、投影重叠/近平行范围、横向错位及介质信息 |
| 参考结构 | 中间铜的网络与连续性、槽/孔/板边及换层回流 |
| 局部整理前后 | 受影响路径及端点、采用一致计量范围的长度/偏斜、换层与过孔数量、最小间距或有效载流截面等适用指标；注明改动收益、约束限值、关联复核结果及保留/恢复决定 |

几何扫描只能筛选疑点。计算角度需要正确的连接图，层间检查需要实际 Z 顺序及铜区；网络总长度、线段方向统计或顶底截图本身不能证明无串扰。
